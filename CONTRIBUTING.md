# Contributing Guidelines

Thank you for considering contributing to the Budget Tracker App!  
Your contributions are highly appreciated and help make this project better.

---

## How to Contribute

### 1. Fork the Repository

Click the **Fork** button on the top-right corner of this repository to create your own copy.

### 2. Clone Your Fork

Use the following command to clone your forked repository:

```bash
git clone https://github.com/<your-username>/budget-tracker-frontend.git
```

### 3. Create a New Branch

Before making changes, create a new branch for your feature or fix:

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes

Implement the desired changes or bug fixes in your local branch.

### 5. Commit Your Changes

Write clear and descriptive commit messages:

```bash
git commit -m "Add: implemented dark mode toggle button"
```

### 6. Push Your Changes

Push the changes to your fork:

```bash
git push origin feature/your-feature-name
```

### 7. Create a Pull Request

- Go to the original repository: mayurrogheliya/budget-tracker-frontend
- Click "Compare & pull request"
- Provide a detailed description of your changes and submit the pull request

---

## Reporting Issues

If you find a bug or have a feature request:

1. Go to the Issues tab
2. Click New Issue
3. Provide a clear and detailed description (with screenshots if possible)
